The **Agentova for n8n** community node brings the Agentova API directly into your n8n automation canvas. With it, you can create and retrieve users, list companies, and build powerful multi-step workflows — all without writing a single line of code. If you do want to write code, the node is also available as an AI tool inside n8n agent workflows.

## Quick Start

<Steps>
  <Step title="Install the node">
    Open your n8n instance, go to **Settings → Community Nodes**, and install `n8n-nodes-agentova-poc`.
  </Step>
  <Step title="Add your API key">
    Create a new credential of type **Agentova Poc API** and paste your Agentova API key.
  </Step>
  <Step title="Add the node to a workflow">
    Open or create a workflow, search for **Agentova Poc** in the node palette, and drag it onto the canvas.
  </Step>
  <Step title="Pick a resource and run">
    Select a resource (User or Company) and an operation, then execute your workflow.
  </Step>
</Steps>
