The Agentova for n8n community node brings the Agentova API directly into your n8n workflows, letting you create, read, update, and delete your Agentova data without writing a single line of code. Whether you are syncing CRM records, orchestrating multi-step automations, or wiring Agentova into an AI-powered pipeline, this node gives you a first-class integration that feels native inside n8n.

## What Problem It Solves

Managing users and companies across multiple tools often means juggling webhooks, custom scripts, or brittle HTTP Request nodes filled with hand-crafted headers and body schemas. The Agentova node removes that friction by exposing a structured, point-and-click interface for every supported operation. You configure your API key once, and every workflow you build reuses that credential automatically.

## Supported Resources

The node currently exposes two core resources from the Agentova API.

<CardGroup cols={2}>
  <Card title="Users" icon="user">
    Create, retrieve, update, and delete individual user records in your Agentova account. Perfect for onboarding flows, profile sync, and user lifecycle automation.
  </Card>
  <Card title="Companies" icon="building">
    Create, retrieve, update, and delete company records. Use this to keep your Agentova company data in sync with your CRM, data warehouse, or any other system in your stack.
  </Card>
</CardGroup>

## Available Operations

Each resource supports a full set of CRUD operations so you can model virtually any data workflow.

| Resource | Operations |
|----------|-----------|
| **Users** | Create, Get, Get Many, Update, Delete |
| **Companies** | Create, Get, Get Many, Update, Delete |

## Two Ways to Use the Node

The Agentova node is designed to slot into your workflows in two distinct modes, giving you flexibility depending on the complexity of your automation.

<CardGroup cols={2}>
  <Card title="Standard Node" icon="circle-nodes">
    Drag the node into any workflow and wire it between triggers and other actions. Ideal for straightforward create-or-update pipelines where you know exactly which operation to run at build time.
  </Card>
  <Card title="AI Tool Node" icon="robot">
    Attach the Agentova node as a **tool** to an AI agent node (such as the n8n AI Agent). The agent can then decide at runtime which operations to call based on natural-language instructions — no hard-coded operation selection required.
  </Card>
</CardGroup>

<Tip>
  Using the node as an AI tool is especially powerful when you want a conversational agent to look up or update Agentova records on behalf of a user, without you having to anticipate every possible request in advance.
</Tip>
