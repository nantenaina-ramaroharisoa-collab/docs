The Agentova for n8n community node brings the Agentova API directly into your n8n workflows, letting you read and create your Agentova data without writing a single line of code. Whether you are syncing user records, pulling company data into downstream tools, or wiring Agentova into an AI-powered pipeline, this node gives you a first-class integration that feels native inside n8n.

## What Problem It Solves

Managing users and companies across multiple tools often means juggling webhooks, custom scripts, or brittle HTTP Request nodes filled with hand-crafted headers and body schemas. The Agentova node removes that friction by exposing a structured, point-and-click interface for every supported operation. You configure your API key once, and every workflow you build reuses that credential automatically.

## Supported Resources

The node currently exposes two core resources from the Agentova API.

<CardGroup cols={2}>
  <Card title="Users" icon="user">
    Retrieve a list of users, look up a single user by ID, or create a new user record in your Agentova account. Perfect for onboarding flows, profile sync, and user lookup automation.
  </Card>
  <Card title="Companies" icon="building">
    Retrieve a list of company records from your Agentova account. Use this to pull company data into your CRM, data warehouse, or any other system in your stack.
  </Card>
</CardGroup>

## Available Operations

The node exposes the following operations for each resource.

| Resource | Operations |
|----------|------------|
| **Users** | Get Many, Get, Create |
| **Companies** | Get Many |

## Two Ways to Use the Node

The Agentova node is designed to slot into your workflows in two distinct modes, giving you flexibility depending on the complexity of your automation.

<CardGroup cols={2}>
  <Card title="Standard Node" icon="circle-nodes">
    Drag the node into any workflow and wire it between triggers and other actions. Ideal for straightforward data-retrieval or user-creation pipelines where you know exactly which operation to run at build time.
  </Card>
  <Card title="AI Tool Node" icon="robot">
    Attach the Agentova node as a **tool** to an AI agent node (such as the n8n AI Agent). The agent can then decide at runtime which operations to call based on natural-language instructions — no hard-coded operation selection required.
  </Card>
</CardGroup>

<Tip>
  Using the node as an AI tool is especially powerful when you want a conversational agent to look up Agentova users or companies on behalf of a user, without you having to anticipate every possible request in advance.
</Tip>
